# 阶段 4：知识库与 RAG 需求

> 版本：v0.2 · 日期：2026-11-23
>
> 状态：基于已确认产品边界的详细需求规划；待实施，本文功能尚未实现。
>
> 所属路线：阶段 1—6 完成完整产品能力，阶段 7 完成 Docker/Compose 部署交付；本阶段建立知识问答闭环。
>
> 文档边界：描述用户需要完成的事情、结果和验收依据，不确定技术实现。

## 1. 背景与目标

只有能够生成回答还不够。使用项目资料回答问题时，用户需要知道资料是否正确进入知识库、找到了哪些证据、答案引用是否成立，以及为什么某次查询没有找到资料。本阶段让用户从导入文档走到可追溯的知识问答，并建立可供阶段 5 批量评测的基础样本。

阶段目标是完成“准备资料 → 检查处理结果 → 比较检索配置 → 回答并引用 → 记录失败问题”的用户旅程。不能以“文档上传成功”代替知识可用，也不能以“回答流畅”代替检索有效。

## 2. 范围与前置条件

| 范围 | 内容 |
|---|---|
| 本阶段包含 | 项目知识库、文档处理与版本、分段预览、检索试验、知识问答、证据引用、Agent 与工作流使用知识、基础问题样本 |
| 后续必交付 | 阶段 5 的批量质量评测、对照实验和优化证据；阶段 6 的扫描文本、表格结构与跨文档多证据问答，并接入应用发布 |
| 本次产品范围外 | 任意图像语义理解、全量音视频知识、通用跨资料关系推理、自动知识采集平台；不得据此缩减上一行的必交付范围 |
| 前置条件 | 阶段 1 的项目权限、模型配置、运行记录及基础预算；阶段 2 的工作流；阶段 3 的 Agent 和上下文管理 |

知识库可独立试用检索。将其交给 Agent 或工作流使用，需要相应能力已经验收；尚未开放的入口应清楚说明原因。

个人用户以自己的租户使用全部知识功能。模型、知识处理所需的外部模型服务及其他收费服务，由用户配置自己的连接与凭据；平台不提供共享模型池或免费额度。缺少所需配置时说明尚不能执行的处理步骤，不能转用其他租户或平台维护者的凭据。

## 3. 角色与典型场景

| 角色 | 场景 | 期望结果 |
|---|---|---|
| 资料维护者 | 导入产品手册并替换旧版本 | 知道哪些文档可用，新旧资料不混淆 |
| 应用开发者 | 为助手选择项目知识库 | 助手只使用获准资料，并能展示引用 |
| 知识质量维护者 | 搜不到缩写、编号或同义问法 | 对照原文定位问题，保存可复查的样本 |
| 业务使用者 | 提问资料未涉及的问题 | 获知证据不足，而非收到编造答案 |
| 项目负责人 | 控制大批量资料处理开销 | 操作前能看到预计工作量、额度和停止条件 |

## 4. 详细功能需求

### PA-P4-001：创建与管理项目知识库

- **使用场景**：有知识管理权限的用户需要按业务主题组织资料。
- **行为要求**：可创建、查看、重命名、描述、停用知识库，明确所属项目、维护者和可使用范围。列表展示文档数量、可用与失败数量以及最近变更时间。停用前展示受影响的 Agent、工作流等使用关系。
- **边界与异常**：知识库为空时明确提示；同名知识库应能区分。停用后不得继续接受新知识查询，既有引用仍按当前权限决定能否查看。
- **验收 PA-P4-001-A1**：创建两个不同主题知识库后，用户能分别查看和选择它们；无权限用户无法看到其内容或查询结果。
- **验收 PA-P4-001-A2**：停用被使用的知识库时能看到影响说明，随后发起的查询获得明确的不可用结果。

### PA-P4-002：导入文档并确认处理范围

- **使用场景**：维护者选择一个或多个文件准备建立知识内容。
- **行为要求**：支持常见 TXT、Markdown、具有可提取文本的 PDF、DOCX 文档。提交前显示文件名称、类型、大小、目标知识库、重复情况、处理范围及将使用的本租户服务配置；显示可获得的工作量、Token 用量与费用估算，未知项必须标明。用户可取消未启动的处理，处理产生的用量归入知识任务并可在统一面板查看。
- **边界与异常**：不支持的格式、空文件、损坏文件、超出已公布限制的文件逐个说明。发现扫描件或无法读取的内容时提示本阶段能力范围；不得显示为完整成功。重复文件应让用户选择跳过、作为新资料或更新已有资料，不能静默覆盖。
- **验收 PA-P4-002-A1**：同批包含正常、重复和损坏文件时，每个文件都有独立结果，正常文件可继续处理。
- **验收 PA-P4-002-A2**：额度不足时不启动新的收费处理；已启动部分的状态、费用和停止原因可查看。

### PA-P4-003：查看处理状态和内容预览

- **使用场景**：文件已提交，维护者需要判断其是否可用于问答。
- **行为要求**：区分待处理、处理中、待检查、可用、失败和已取消等面向用户的状态，展示当前进展与失败位置。可预览提取出的文本、标题、页码或段落位置，对缺失、乱码、顺序错误作标记。用户可修正文档来源后重新提交，或修订可编辑的处理结果并形成新版本。
- **边界与异常**：部分内容无法读取时显示缺失范围；未经确认的部分结果不得伪装为完整文档。任务长时间无进展时，用户可获得明确状态并停止等待。
- **验收 PA-P4-003-A1**：包含特殊字符和多页内容的测试文档，处理结果可与原文逐段核对。
- **验收 PA-P4-003-A2**：失败文档显示原因与可采取的操作，不能参与普通知识问答。

### PA-P4-004：更新资料并保留明确版本

- **使用场景**：同一手册发布新版本，维护者希望更新知识内容。
- **行为要求**：记录来源、版本、发布日期或业务生效日期，区分上传时间与资料生效时间。更新成功并确认可用后，用户才能将新版本设为当前版本；旧版本的历史使用记录可追溯。支持在权限允许时按版本查询。
- **边界与异常**：新版本处理失败时，已可用版本保持可用，界面说明更新失败。资料存在冲突或多个有效版本时，应显示选择依据，不得仅因上传较晚就推断业务上更新。
- **验收 PA-P4-004-A1**：先使用旧手册问答，再上传失败的新文件，后续问答仍能使用旧版并显示正确版本。
- **验收 PA-P4-004-A2**：成功切换后，新查询采用指定版本；旧运行记录保留当时采用版本的信息。

### PA-P4-005：预览与调整知识分段

- **使用场景**：维护者发现回答缺少标题、条件或上下文，需要调整资料组织方式。
- **行为要求**：可查看每个知识片段对应的原文位置、标题和相邻内容；至少可以按长度边界、标题与段落结构两种方式配置资料分段，并选择是否保留必要的前后重叠内容，预览变更影响。对标题、列表、表格说明和代码内容是否被割裂提供可检查结果。重新处理形成独立版本并保留前后对照；表格结构的专门处理在阶段 6 联验。
- **边界与异常**：调整不得修改原文事实。处理量较大时先显示影响范围与可获得的成本估算；取消或失败不得替换已可用版本。
- **验收 PA-P4-005-A1**：对同一资料建立两种分段配置，用户能对照原文检查边界，并保存各自版本。
- **验收 PA-P4-005-A2**：更换分段后，原问题的标准证据仍可定位到原文，而非因片段编号改变失去依据。

### PA-P4-006：执行可解释的检索试验

- **使用场景**：用户想确认知识库能否找到精确术语、编号和意思相近的表达。
- **行为要求**：提供关键词、语义和组合检索的可选试验方式；允许限定知识库、文档、版本、时间范围和结果数量。结果展示片段、来源、版本、位置、排列顺序、采用的配置、耗时和可获得的费用信息。可保存配置及一次查询记录。
- **边界与异常**：筛选后没有资料、配置不可用、处理尚未完成、服务失败应分别说明；未经授权的资料不出现在候选内容、结果摘要或调试信息中。不同方式的相关性分值不得被当成同一尺度直接比较。
- **验收 PA-P4-006-A1**：用同一问题分别运行三种方式，能查看各自证据及配置，并回到指定原文位置。
- **验收 PA-P4-006-A2**：限制到某个版本后，结果中不混入其他版本；结果为空时可看到生效的过滤条件。

### PA-P4-007：试验问题改写和复杂问题拆分

- **使用场景**：原始问法过短、使用别名或同时包含多个子问题，导致证据不足。
- **行为要求**：用户可选择保留原始查询、生成更明确的问法、尝试多种问法或分解子问题。每次试验保留原问题，显示实际使用的问法及其证据来源，允许关闭转换并对照结果。转换不得擅自改变实体、日期、否定条件等任务约束。
- **边界与异常**：歧义无法消除时提示用户补充，不得把猜测当成已确认事实。转换次数和新增费用受任务预算约束；不得声称启用后必然提高召回率。
- **验收 PA-P4-007-A1**：对带编号和日期限制的问题进行改写，用户能检查这些限制是否保留，查看每种问法的结果。
- **验收 PA-P4-007-A2**：达到转换次数或费用上限后停止新增试验，保留已有结果并说明原因。

### PA-P4-008：整理证据并保持必要上下文

- **使用场景**：检索到了重复片段，或只找到结论而缺少适用条件。
- **行为要求**：用户可选择对候选证据重新排序、去重以及补充相邻段落；显示整理前后的证据、被移除或补充内容和采用配置。证据数量与篇幅受已配置的任务限制约束，优先保留回答所需的条件、例外与来源。
- **边界与异常**：扩展上下文不能越过资料权限或混合冲突版本。超出篇幅预算时明确指出内容被裁减；未找到的上下文不得由模型补写成原文。
- **验收 PA-P4-008-A1**：查询有例外条件的规定时，结果可展示结论及其适用条件，新增内容均能定位原文。
- **验收 PA-P4-008-A2**：重复证据被合并后保留必要来源；用户能判断最终交给回答过程的实际证据范围。

### PA-P4-009：生成带有效引用的知识回答

- **使用场景**：用户希望基于资料获得可核查的回答。
- **行为要求**：回答应区分有证据支持的结论、资料之间的矛盾和仍需确认的内容；关键事实带可打开的引用，展示资料名、版本与位置。证据不足时说明不足的具体方面，可请求补充材料或问题条件。
- **边界与异常**：不存在的引用、引用与结论不对应、引用指向无权限内容均属于问题；检查到异常时应标记或阻止把该结论当成已证实答案。资料中的指令性文字不能改变用户任务、权限或工具授权。
- **验收 PA-P4-009-A1**：对答案明确的问题，逐条核对关键结论与引用原文；引用能打开正确版本和位置。
- **验收 PA-P4-009-A2**：对无答案、证据冲突和含诱导指令的资料，分别呈现不足、冲突说明或正常忽略无关指令的结果。

### PA-P4-010：在 Agent 和工作流中复用知识能力

- **使用场景**：应用开发者将已验证的检索配置用于实际助手或流程。
- **行为要求**：可为 Agent 选择允许使用的知识范围，为工作流配置知识检索步骤；可分别使用“仅取证据”和“根据证据回答”的结果。运行记录显示采用的知识库、资料版本、检索配置与引用，Token 和费用并入所属任务且不重复计入父子任务总额。保存的检索配置可供阶段 5 对照评测和阶段 6 应用发布使用；公开应用模板不能自动携带私有资料或原作者凭据。
- **边界与异常**：绑定知识库不会额外授予权限。运行期间发现停用、撤权、资料不可用或预算不足时，应给出明确结果，并按用户已选择的失败处理方式结束或继续不依赖该知识的步骤。
- **验收 PA-P4-010-A1**：同一检索配置可在独立试验、Agent 和工作流中使用，三处都能查看实际证据及其来源。
- **验收 PA-P4-010-A2**：应用使用者无权访问的资料不会因开发者绑定知识库而被间接暴露。

### PA-P4-011：建立最小问题与证据基线

- **使用场景**：阶段 5 尚未完成，维护者也需要知道知识调整是否改善实际问题。
- **行为要求**：可保存问题、期望结论、人工确认的原文证据、问题类型与核验状态。支持记录某次试验是否命中、缺少哪些证据、答案是否符合预期以及备注。样本至少覆盖精确术语、同义问法、跨段落、无答案、旧版本与权限边界。
- **边界与异常**：自动生成的问题未经人工核验应标为候选；未列全相关证据时不能宣称计算出了真实完整召回率。小样本结果仅作为观察依据，不能表述为普遍提升。
- **验收 PA-P4-011-A1**：同一批人工确认样本可检查两种配置的结果，逐题保存证据和判断，供阶段 5 接续使用。
- **验收 PA-P4-011-A2**：无答案样本与有答案样本分别记录，不能用“未找到”统一判定成功或失败。

### PA-P4-012：使资料撤权、停用和删除真实生效

- **使用场景**：资料被收回、用户失去访问权，或维护者删除过时内容。
- **行为要求**：操作前展示影响范围；确认后，新的查询、证据展开和引用访问遵守最新权限及可用状态。历史运行可保留允许保留的状态和费用信息，但不能继续向失去权限的用户展示受限正文。删除进度、失败与仍需处理的历史副本范围应可查看。
- **边界与异常**：已在操作发生前合法取得或下载的副本不能被宣称已远程撤回。正在进行的任务应停止继续使用已撤权材料，并明确结果是否因此不完整；导出和分享遵守同样权限。
- **验收 PA-P4-012-A1**：撤销某文档的访问权后，再查询、打开旧引用或导出结果，都不能获得该文档正文。
- **验收 PA-P4-012-A2**：删除操作部分失败时不会显示全部清除，用户能看到剩余处理范围。

## 5. 必交付的知识处理与检索能力矩阵

本矩阵明确平台最终提供哪些可操作能力。每种方式都应有名称、用途、适用资料、可修改设置、实际结果、版本和费用说明；不把某个算法名称或提升百分比作为验收替代品。阶段 4 标为必交付的能力必须真实可运行，不能只有菜单选项。

| 能力 | 用户可以做什么 | 交付阶段与需求 | 验收依据 |
|---|---|---|---|
| 长度与结构分段 | 选择长度边界或标题/段落边界，预览重叠内容和原文位置 | 4；PA-P4-005 | 同一文档形成两种可查看、可保存的配置与处理版本 |
| 关键词检索 | 查找编号、专有名词和精确表达 | 4；PA-P4-006 | 术语样本命中原文，筛选条件可见 |
| 语义检索 | 使用意思相近但表达不同的问题寻找资料 | 4；PA-P4-006 | 同义问法样本可对照，结果能定位来源 |
| 组合检索 | 结合精确表达和语义结果形成候选 | 4；PA-P4-006 | 展示最终候选及各方式的贡献，不混比分值口径 |
| 问题改写与多问法 | 查看实际问法、保留原问题并开关改写 | 4；PA-P4-007 | 实体、时间、否定条件不被擅自改变，新增调用受限 |
| 复杂问题拆分 | 查看子问题及各自证据，检查是否覆盖原问题 | 4；PA-P4-007 | 缺少某个必要子问题证据时明确显示不完整 |
| 结果重排与去重 | 对候选重新排序，移除重复而不增加虚假覆盖 | 4；PA-P4-008 | 对照前后顺序、来源和保留证据 |
| 邻近内容与父段补充 | 从命中片段展开相邻内容或所属完整段落 | 4；PA-P4-005、PA-P4-008 | 补充内容仍来自授权原文，篇幅裁减可见 |
| 资料、时间和版本过滤 | 限定知识范围并检查生效条件 | 4；PA-P4-004、PA-P4-006、PA-P4-012 | 不返回无权限、已停用或不符版本的正文 |
| 引用、证据不足与矛盾说明 | 逐项核查结论、引用及缺失内容 | 4；PA-P4-009 | 无答案、冲突资料和错误引用的独立样本 |
| 配置保存与应用采用 | 保存精确配置版本，用于 Agent、工作流、评测和后续发布 | 4—6；PA-P4-010、PA-P4-011 | 试验版本与实际采用版本可对照，旧运行不被改写 |
| 扫描文本与表格结构 | 检查扫描文字、行列标题、单元格关系及来源位置 | 6；PA-P6-011 | 经人工确认的扫描件与表格样本逐项核对 |
| 跨文档多证据问答 | 关联多份资料支持完整答案，标出缺失证据 | 6；PA-P6-011 | 不能用命中一份资料代替完整证据覆盖 |

语义化分段、文档背景补充、更多检索策略可通过已确认的插件能力扩展并进行对照；具体内置策略由技术设计说明。GraphRAG、全量音视频与任意复杂图像理解属于后续研究，不计入本次完整版本承诺，也不能成为推迟本表能力的理由。

### 5.1 效果改善的依据

每次改变分段、查询处理、检索方式、证据整理或资料范围，均保留原配置与候选配置。阶段 4 使用人工确认样本逐题检查，阶段 5 使用版本化数据集与相同口径批量比较。报告必须同时给出改善、回归、无答案题、权限场景、耗时、Token 和费用变化；不存在所有策略必然提升召回的承诺。最终采用和回退由有权用户决定，不自动替换已发布应用。

## 6. 信息、权限与质量要求

资料、处理结果、证据、引用和问题样本必须有清楚的租户、项目归属与来源；资料版本及业务生效时间不得被上传时间替代。查看原文、编辑资料、调整配置、执行试验、导出证据分别受对应权限约束。敏感文档进入外部服务前应遵守项目已确认的使用范围。公共仓库只发布经审核的可共享资源版本，不能使私人知识库或源文档随应用模板默认公开。

性能与容量目标在需求确认时按目标文件规模、语言和并发使用场景确定。本草案不承诺固定召回提升比例、万能文件识别能力或任意资料的完整答案。具体非功能要求遵守[跨阶段要求](../03-cross-cutting-requirements.md)。

## 9. 实施前需细化的参数

- 首批业务资料的语言、文档规模、单文件限制，以及表格和代码内容的最低保真要求。
