## 2. 首次部署和最小配置

- [ ] 使用正式交付包，无需开发者在现场补文件或编译项目。
- [ ] 操作者仅填写规定的数据库与中间件密码；无需安装独立数据库、改服务地址或手写初始化内容。
- [ ] 前置条件不足、端口冲突、密码缺失和镜像不可取得时有明确提示。
- [ ] 约定的一次启动操作完成目录准备、密钥生成、服务启动、初始化与健康检查。
- [ ] 自动生成的秘密不会进入公共日志或镜像，重启后继续使用。
- [ ] 首个管理员通过本机一次性引导建立，无公开默认管理员密码，已用引导不再有效。
- [ ] 主站与插件静态入口、证书信任方式和实际地址明确；无需额外DNS配置即可使用自定义前端，内部管理端口没有默认暴露。

## 4. 持久化、恢复和升级

- [ ] 数据库、缓存必要状态、搜索内容、对象资料、插件包、前端产物、任务输出、日志、平台密钥和备份都有明确挂载及生命周期。
- [ ] 普通停止和再次启动保留账号、密码、个人Key、资料、插件版本与必要任务状态；不重复初始化覆盖数据。
- [ ] 中断后不会盲目重放外部副作用，未知结果保持可见。
- [ ] 完整备份包含对应数据、对象、插件及解密所需密钥；一致性与验证清单明确。
- [ ] 在隔离空环境恢复，并验证租户、凭证可用、资料、插件、检索和关键任务；备份文件存在不是恢复成功。
- [ ] 升级检查版本兼容并保存升级前恢复点；迁移失败时不会误报完成。
- [ ] 不支持直接降级的数据版本，通过兼容恢复方案处理，没有盲目替换旧镜像。
