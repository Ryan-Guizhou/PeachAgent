无关任务尚在运行不妨碍本 PR 完成自己的验证；本 PR 的必要构建与验收未通过则不能合并。纯文档不编译，不能写“编译通过”；新增代码也不能写“无构建入口，因此不适用”。

## 合并前核对

- [ ] 范围符合 Issue 与已确认需求、设计，没有无关变更。
- [ ] 当前提交经复查，没有明显错误或未解决冲突。
- [ ] 代码／可执行配置完成对应真实验证，必要编译通过。
- [ ] 本 Issue 全部必需验收项已满足；未验证项没有标成通过。
- [ ] 凭证、租户内容和其他敏感数据没有进入提交或公开日志。
- [ ] 文档与追踪更新，拟定能力没有被写成已实现。
- [ ] 总规划只被关联，不随本 PR 关闭。
