### 历史需求覆盖记录

- 注册、登录、过期、退出、本地恢复与内部返回路径可操作；密码明文和恢复码不进入持久存储、工作区导出或 URL。
- 账户切换重载前发生延迟保存，仍写入启动时捕获的旧账户 key，不覆盖另一个工作区。旧演示数据只属于演示身份。
- 侧栏多次更新保持同一 DOM 节点、scrollTop 和链接焦点；点击当前菜单不导航，程序化同 hash 刷新保留位置且不增加历史。前进后退与双 history 事件均有检查。此项基于 DOM/history 模型，不是浏览器原生滚动实测。
- 模型分六类维护，LLM／向量／重排不能混选；能力声明、停用、归档和引用参与实际校验。名称与厂商 Model ID 不能绕过稳定 ID 检查。
- 模型和服务商更改不会悄悄更新旧发布版本；新发布父配置不会改写所引用子 Agent 的已发布模型；新 LLM 节点采用用途默认项。
- 知识库维护向量／重排配置及版本，本地检索产生对应模型阶段和用量记录；停用重排后明确报错，可显式跳过重排。
- 规划按父允许范围创建运行专属 Agent，用户可扩大模型池并自动分配或手动覆盖；任务输入实际包含上游结果。临时 ID 不混入永久 Agent 列表。
- DAG 循环、工具越权、能力不足、预算／并发／深度超限被阻断。拒绝与失败停止下游，登出和停止递归取消待审批及排队任务；已产生回执保留。
- 从计划详情执行仍关联原 Chat 会话，同次重复点击不产生重复协调 Run。计划创建中页面自动从 loading 更新至成功或准备错误。


- 申请、审批、领取、停用、吊销、轮换与限额参与本地实际校验；Key 明文不进状态、日志或 URL，重载后只能使用已保存 Key 或轮换。
- API 调用使用已发布快照，日志关联相同 Run 和 Trace；输入、鉴权、权限、额度错误均在执行前返回。
- 评测集可增删改、真实导入导出、维护规则、保存版本；按实际逐条运行输出计算规则分数，支持停止、重试、复核和比较。
- API 或普通运行能回流到可编辑评测样例，保留来源 Run 和 Trace；没有强制参考输出。
- 用户维护的知识正文实际改变 Agent 和工作流结果；旧服务、旧评测与历史运行的知识、Prompt、Skill、子流程内容不漂移。
- 非 topic 的中文 Prompt 参数支持 Workflow 变量绑定，以及 Agent 的 {{message}} 与固定值填参。
- 已发布 Agent 不继承草稿专属字段；显式缺失的 Agent 不退回其它 Agent；未发布依赖不能成为对外服务的隐式来源。
- 市场发布与安装保留真实工作流图；MCP 模板保存后只有一个管理对象，未配置能力时不显示已连接。
- 业务 token/password 等字段持久化保真；存储失败持续提示并可导出备份，恢复后保存返回成功。

- 纯条件分支可以成功完成，零回执、零返回、零文件。
- 插件写入指定数据表后，输出节点可选择 none；状态为 done，保留操作回执，不生成文件。
- 研究图在人工确认后写入目标文档空间，返回值为空，文件数组为空。
- 只有显式成果节点生成可下载文件；结构化数据通过输出节点返回。
- 无返回模式忽略旧的返回字段，不因不存在的可选输出而失败。
- 写入完成状态未知时保留 unknown，不生成虚假确认回执。

### 运行与集成

- 上游绑定解析、类型不匹配、未产生与 null 的区别。
- IF/空结果路径、互斥汇合、并行与部分失败、循环上限、迭代位置保留。
- 重试有独立 attempt，错误出口进入配置的回退节点。
- 当前审批 token、重复提交保护、拒绝无写入、审批期间连接停用重检。
- 参数、工具 Schema 与图的快照独立；固定工具版本缺失时明确报错。
- 新连接通过唯一工具 ID 调用已知模拟适配器，Agent 参数仍来自当前目标。
- 单节点调试、从节点运行不重放之前成功的写入。
- Agent 单独 Chat 使用共享 MCP/插件执行器；工具调用 ID 与 Trace 相同。
- Agent 会话参数在启动时冻结，中途修改只影响下一轮。
- 执行旧计划时保留明确选择的计划快照；工作流绑定解析固定发布版本。
- 工作流 Agent 节点委托同一 Agent 执行路径，父子 Run 不重复计入模型费用。
- Resource/Prompt 子运行在创建时继承父 Trace ID。
- Trace 重测使用节点实参，而不是误把工作流输入当工具参数。
- 人工输入 UI 将 integer、object、array 解析成正确类型后交给执行器。
- 最终回答预算包含工具结果作为模型输入的 Token。
- 页面刷新后保留旧记录和回执，不自动重放未完成操作。

## 实现边界

账户认证和恢复为浏览器本地演示，没有验证真实邮箱或部署身份服务。自动分工使用本地规则，向量／重排使用确定性算法模拟。外部工具、模型响应、连接发现和协议内容来自本地模拟适配器；条件、参数和状态流转按图实际执行。扩展节点没有真实数据库、沙箱、Webhook 或定时服务。嵌套 body 和部分复杂配置使用高级 JSON；没有完整嵌套子画布。质量评分按用户维护的确定性规则计算，不代表真实语义质量，也没有接入 LLM 判分。API 网关、服务端身份与密钥管理、向量数据库、文档解析服务、后台队列和远端存储仍待后续实现。
