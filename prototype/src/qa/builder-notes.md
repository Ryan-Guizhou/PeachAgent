# 工作流实验台验证记录

日期：2026-11-23。

## 本轮实现

`builder.js` / `builder.css` 负责 `workflows` 和 `workflow` 页面。运行、节点测试和外部工具模拟统一调用 `Studio.Runtime`；运行详情与 Trace 由独立追踪模块负责。本模块不再注册旧版 `tasks` / `task` 页面，也不再使用固定计时器的 `S.startRun` 编排工作流。

- 从共享目录生成 37 类节点库，按分组或名称搜索；配置字段、输入和输出契约来自 Runtime 元数据。
- 独立节点与边模型。端口连接、连线编辑／删除、禁止任意回环、节点拖动／方向按钮移动、缩放、自动排列、撤销和重做。
- 六类节点面板：基础、输入、配置、输出、策略、调试。原生选择框、共享表单样式、共享对话框、通知与错误反馈。
- 参数支持常量、类型化上游引用、模板和受控表达式；变量选择器只列出合法上游。MCP／插件直接选择具体工具动作，输入由工具 Schema 驱动。
- IF 条件与循环继续条件使用可视表单；Switch case、输入字段、人工输入字段、互斥分支候选来源可增删。字段映射可在输入面板直接绑定来源。
- 并行、迭代、循环、子流程、人工输入和错误处理配置接入共享图执行器。复杂嵌套图、结构化契约和 ELIF 组提供高级 JSON 编辑；不声称已提供独立的容器子画布。
- 保存草稿、独立发布快照、版本列表、市场安装副本、工作流复制。外部模块可通过 `Studio.Workflow.invalidateDraft(id)`（别名 `Studio.WorkflowEditor.invalidate(id)`）通知编辑器重新读取保存的草稿。
- `#workflow?id=...&node=...` 支持选择从能力中心直接加入的节点。
- 调试输入、模拟场景、单节点测试、显式上下文覆盖、从节点运行、断点恢复、人工处理、停止与独立运行记录。
- 运行底部面板订阅真实 Runtime 事件；查看已解析输入、输出、错误、尝试记录和完整 Trace。

## 完成状态与产物

工作流不强制返回文件。结束节点支持“不返回内容”与“返回结构化数据”；对话回复与显式成果生成分别使用各自节点。运行面板分别显示：完成状态、是否有返回数据、动作回执数量和文件数量。写入节点可以先将内容放到指定位置，之后流程以零返回值、零文件正常结束。

外部服务全部使用本地模拟适配器。图逻辑、参数解析、分支与迭代由实际配置驱动，界面不将模拟写入描述为真实外部写入。

## 已执行验证

- `node --check builder.js`：通过。
- `node qa/workflow-contract.cjs`：使用 Node VM 加载真实 `core.js`、`runtime.js`、`builder.js`，渲染六个示例流程，以及全部 37 类节点的六个配置页，共 228 个工作流／检查器变体：通过。
- 每个变体检查所有声明的 action、form 已注册，DOM ID 唯一，`label for` 指向实际字段：通过。
- 草稿节点复制 → 保存 → 撤销 → 再保存，验证节点数和草稿独立状态：通过。
- 市场工作流重复安装保持同一安装 ID；安装后的模板 → 结构化返回流程通过真实 Runtime 执行，返回值随输入变化：通过。
- 输出引用路径按实际节点结果结构显示；单节点测试只传调试上下文，不用流程输入覆盖节点的具体参数绑定；从节点运行保留上游结果形状。
- 普通绑定的数字、布尔和对象类型保留；JSON 编辑错误保留原文并阻止保存，修复后清除错误。
- Runtime 行为验证由 `qa/runtime-contract.cjs` 负责，避免在 UI 模块重复实现执行规则。

## 未验证与明确边界

当前环境未完成真实浏览器验收。因此不把 Node VM 渲染检查当作视觉、点击、键盘、焦点约束、拖动、窄屏或原生选择框展开验证。浏览器环境此前存在明确策略限制，本轮没有尝试绕过。

模板／代码／外部节点的执行能力以 Runtime 受控适配器范围为准：任意用户代码、数据库、网络服务与定时服务不会在此 HTML 原型内真实执行。容器内部流程目前通过高级 JSON 配置，UI 不宣称完整的嵌套子画布编辑器、运行差异比较或任意图重放已实现。
