# OTRYX Studio · 可交互高保真原型

原生 HTML、CSS、JavaScript 实现的 AI 应用工作空间，保留雾白与深海绿的原创视觉。当前主路径是：**构建 Agent／工作流 → 维护内容与工具 → 发布应用服务 → API Key 接入 → 运行追踪 → 数据集评测与改进**。

原型中的数据维护、变量传参、条件选路、审批、版本和规则评分按实际配置执行。外部模型、MCP、插件、HTTP、数据库和目标位置写入由本地适配器模拟；没有部署真实 API、向外发送业务请求或产生模型费用。

## 打开与保存

- 从上一级下载 `OTRYX_Studio.html` 后用桌面浏览器打开；全部样式与脚本已内联。
- 开发时可打开本目录 `index.html`，或从仓库根目录执行 `python -m http.server 8080 --directory prototype` 后访问 `http://localhost:8080/src/index.html`。
- API Key 使用 Web Crypto 生成与校验；若浏览器限制当前打开方式，页面会提示改用本地 HTTP 服务。
- 状态保存在浏览器 localStorage；在“空间设置 → 偏好”可重置演示。存储写入失败会保留明确的提示，不应把内存中的修改当作已持久保存。
- 旧工作流保留迁移备份；旧运行没有事件时会说明，避免补造调用链。旧知识正文与提示词会迁入对应入口，仅有文件元数据的历史记录需补正文后才能检索。

## 体验路径一：应用发布与 API Key 申请

1. 在 Agent 或工作流编辑器完成配置，发布一个执行版本。
2. 在 **发布与 API** 创建应用服务，选择已发布来源与版本。新服务为待发布状态；上线后才允许签发与调用。
3. 服务默认使用固定快照。源配置后来更新，不会自动替换已上线版本；在服务概览显式新增版本或切换已有版本。
4. 在 **API Key** 页，所有者可直接签发；也可开启申请并切换“调用方预览”，填写用途、权限、分钟／日配额和有效期后提交。
5. 切换“所有者预览”批准或驳回。批准可以收窄授权，不能扩大申请范围。调用方领取后明文只显示一次。
6. 在 **接入与试调** 填写 Key、终端用户 `user` 和 `inputs`，运行本地 Playground。也可查看 curl、JavaScript、Python 示例和导出的 OpenAPI 契约。
7. **调用日志** 保留 requestId、runId、traceId、服务版本、Key 与实际运行状态；点击进入同一条运行。
8. 停用、启用、吊销、到期和轮换都会影响后续授权。轮换立即使旧 Key 失效，保留原权限和到期时间。

这里只是本地角色预览与 API 模拟。`.example` 地址不可用于生产调用。Playground 校验指纹、应用作用域、invoke／read／stop 权限、终端用户、输入 Schema、服务状态和额度，然后运行共享 Runtime；不会发 HTTP 请求。开始调用返回模拟的 202 接受状态，最终完成、失败或等待需看运行状态。对外 MCP 发布尚未接入。

## 体验路径二：维护评测集并检查改动

1. 打开 **质量评测 → 新建评测集**，填写名称、说明和可选输入 JSON Schema；允许从空集开始。
2. 添加样例：输入 JSON、可选参考输出、预期运行状态、标签和分组。支持编辑、删除、搜索、分页、多选删除和批量分组。
3. 批量内容可从 JSON、JSONL、CSV 导入，先选字段映射并预览错误，再决定跳过、更新或保留重复记录。CSV 支持引号、逗号与换行。单次最多 1,000 条、文件不超过 2 MB，单集最多 5,000 条。
4. 在 **评判规则** 维护“包含参考内容”“与参考输出相等”“JSON 字段与类型”“运行状态”“非空返回”，设置启用状态和通过阈值。规则等权；没有接入 LLM 判分。
5. 保存数据集版本，启动任务时选择已发布 Agent／工作流版本、数据版本与分组。使用当前工作副本时，也会在启动瞬间固定它。
6. 每条输入通过本地运行器产生实际输出，再计算规则结果；任务记录固定样例、规则、应用依赖和知识内容。随后改数据或配置不会改写历史。
7. 查看逐题实际／参考、判定原因、状态、耗时和估算用量；可停止任务、重试失败项、人工复核。人工结论与规则结果分开保存。
8. 选择另一任务逐题比较。只有相同样例且评分规则一致时显示分差，样例或规则变化会明确说明。
9. 从运行详情或问题样例 **加入评测集**，核对和编辑后保存，保留 runId／traceId 来源。当前实际输出只是编辑起点，不自动认定为正确答案。

评测默认执行只读路径。写工具、数据库和人工等待会被阻断；不会自动批准操作。被阻断、错误或未执行的样例没有虚构分数。无返回流程可以按运行状态通过，不会因没有文件被判错。数据集支持归档、恢复及导出；删除最后一条样例后仍正常可用。

## 体验路径三：知识、提示词与 Skill 由用户维护

**知识库**支持创建、编辑、归档与恢复；每个库独立维护文档正文、分段长度、重叠长度和版本。粘贴正文或导入 TXT／Markdown／JSON，检查分段后做检索测试。结果展示来源文档、分段和匹配度；关键词模式直接匹配正文；向量／混合和重排配置使用明确标记的本地模拟阶段，没有请求真实模型服务或连接向量库。支持的正文文件不超过 512 KB，正文保存上限为 200,000 个字符；PDF／Word 解析尚未接入。

**提示词与 Skills**支持编辑正文、模板参数、依赖说明、复制、导出、归档和版本查看。它们是可复用上下文；Skill 的依赖说明不会自动授权工具。Agent 能选择本地 Prompt／Skill，也能选择 MCP Resources／Prompts、已发布工作流和子 Agent。Prompt 绑定有独立参数表单，支持 `{{message}}` 引用本轮输入或填写固定值；工作流 Prompt 节点按所选模板的实际参数生成输入 Schema。内置 Skill 也进入内容库维护。

内容被 Agent／工作流运行、服务版本或评测任务使用时留存独立快照。新内容可用于之后明确选择的配置和版本，旧记录继续使用当时内容。

## 体验路径四：MCP 调试、Agent Chat 与调用链

1. 打开 **工具与连接 → MCP → Research MCP → 调试台**，选择“搜索资料”。
2. 按 Schema 表单或 JSON 填参数，切换成功、空结果、工具错误、超时、结构不匹配等场景。
3. 检查结构化输出、原始响应、协议 requestId 和实际事件。测试用例可以保存后重新载入。
4. 将具体工具挂载到 Agent 草稿，在工作台检查能力、范围、版本和执行限制后发布。
5. 进入独立 **Agent Chat**，在“本次能力”调整允许的 MCP／插件工具、模型、资源和执行模式。
6. 输入研究目标并指定目标目录。执行过程调用检索工具，在写入前等待确认，完成后显示模拟写入位置。
7. 工具卡片与运行详情进入同一次执行的调用链；可以检查参数、审批、重试、子运行、事件和快照。

会话调整影响下一轮，已经开始的一轮保留当时配置。全局连接停用或凭证不可用仍阻止后续新调用。

## 体验路径五：工作流的多种完成方式

- **研究简报 · 写入团队空间**：搜索、IF、汇合、迭代、报告与人工确认后写入模拟目标目录；结束时可以没有返回值和文件。
- **多路分析 · 返回结构化数据**：并行、命名汇合、有界循环后返回对象。
- **复用发布子流程**：父输入映射到已发布子流程，查看父子 Run 和依赖版本。
- **更新业务记录 · 无返回值**：模拟按 key 更新数据，保留操作回执。
- **生成文件 · 显式成果节点**：显式生成 Markdown 文件，预览与下载。

主题改为“无结果”或选择空结果场景可以改变分支路径。上下游变量未产生、类型错误、超时和错误出口都会在实际执行中体现。

### 37 个节点族

| 类别 | 节点 |
| --- | --- |
| 入口 | 用户输入、Webhook、定时、插件事件 |
| 智能处理 | LLM、Agent、问题分类、参数提取 |
| 知识与上下文 | 知识检索、文档提取、记忆、MCP 资源、Prompt |
| 工具 | MCP、插件动作、HTTP、代码、数据库、沙箱 |
| 数据处理 | 字段映射、模板、变量赋值、列表操作 |
| 控制流 | IF／ELIF／ELSE、Switch、互斥汇合、并行、迭代、循环、Break／Continue、人工输入、子流程、等待 |
| 完成 | 对话回复、最终输出、显式成果、终止 |

图编辑器包含真实 edges／端口、移动、连线编辑、复制、撤销／重做、缩放、自动布局和图校验。检查器分基础、输入、配置、输出、执行策略与调试；支持上游变量选择、类型检查、模板和受控表达式。单节点、从节点运行、断点与继续创建真实本地运行记录。嵌套 body、ELIF 和复杂 Schema 仍使用高级 JSON，尚无完整嵌套子画布。

## 统一结果模型

| 信息 | 是否必须 | 含义 |
| --- | --- | --- |
| 状态 | 必须 | 运行、等待、完成、失败、拒绝、停止 |
| 返回值 | 可选 | 显式输出的结构化数据或回复 |
| 操作回执 | 可选，零条或多条 | 目标位置、操作内容与调用 ID，注明模拟 |
| 文件 | 可选，零个或多个 | 显式成果节点生成的可预览和下载内容 |
| 内部节点输出 | 按实际执行产生 | 用于传参、调试与调用链，不自动成为返回值 |

**成功完成不要求产物。** 条件判断后不需要操作，也可以正常结束。无返回模式忽略已不适用的返回字段；取消不代表撤销先前完成的写入。外部效果未知时不能伪造成功回执。

## 账户与多模型协作

- 首次打开显示登录页，注册账户有独立工作区；“进入演示空间”使用原有示例和以前保存的数据。密码校验采用浏览器 Web Crypto；不支持它的环境仍可使用演示入口。重置密码是本地演示，不验证真实邮箱所有权。
- 模型中心分别管理服务商连接和模型实例。按类型维护参数、能力、默认用途和调试输入；模型名或品牌不会自动授予工具调用能力。LLM、Embedding 与 Rerank 选择互相隔离。
- 在 Agent Chat 切到规划，或进入协作计划创建目标。先审阅临时子 Agent 的职责、依赖和模型，再执行。可扩大允许的语言模型池并自动分配，也可逐任务手动指定。
- 总预算、最大子 Agent 数、并发和深度在父策略范围内。写入逐项确认；拒绝、失败、停止及退出都会停止未完成的下游任务。父任务和子运行保留相同 Trace，成本按各运行自身记录只累计一次。
- 侧栏 DOM 常驻；同页刷新只更新活动项、数值和身份文本，不重建滚动容器。路由使用 History API 控制 fragment 地址，避免锚点的原生跳转干扰。

## 明确保留的工程边界

- Agent 的工具规划和模型回复是确定性的本地模拟，不是真实大模型推理。
- API Key 权限和配额在同一浏览器内校验，不能替代服务端身份隔离、持久计数与秘密保管。
- 质量规则来自用户维护的输入和参考，不提供 LLM 语义判分，也不自动生成“优秀”的分数。
- 知识基于本地正文，支持关键词检索与向量／重排配置的本地模拟；真实模型检索、远程抓取、OCR 和大规模索引尚未接入。
- Webhook、调度、真实 MCP HTTP／stdio、数据库和沙箱尚无后端；浏览器不执行任意用户代码或启动进程。
- 运行中断后保存历史并停止，刷新不会自动重放写入。多用户、持久队列、远端追踪上报、生产监控、真实热更新和容器部署仍需正式工程实现。
- Compose 页只导出配置草案，没有可直接拉取的 OTRYX 生产镜像。
